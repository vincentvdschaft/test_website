Phase rotation

Phase rotation is an operation that is required when we want to apply [[time of flight correction]] to [[IQ demodulation|IQ data]]. Apart from indexing the IQ-signal with a delay τ\tauτ, we also need to multiply by e−iωτe^{-i\omega\tau}e−iωτ:

IQ(t−τ)⋅e−iωτIQ(t-\tau)\cdot e^{-i\omega\tau}IQ(t−τ)⋅e−iωτ

Explanation

A modulated signal with carrier frequency ω\omegaω can be written as

x(t)=I(t)⋅cos⁡(ωt)−Q(t)⋅sin⁡(ωt)(1)x(t)=I(t)\cdot\cos(\omega t) - Q(t)\cdot\sin(\omega t) \tag{1}x(t)=I(t)⋅cos(ωt)−Q(t)⋅sin(ωt)(1)

When we do IQ-demodulation we extract the I(t)I(t)I(t), and Q(t)Q(t)Q(t) components from the signal. These are then often combined into a single complex valued number:

IQ{x}(t)=I(t)+i⋅Q(t)(2)IQ\{x\}(t)=I(t) + i\cdot Q(t) \tag{2}IQ{x}(t)=I(t)+i⋅Q(t)(2)

[!info] Note Note the sign difference between the two!

When we perform [[time of flight correction]] we need to apply some delay τ\tauτ to the received signal x(t)x(t)x(t). For regular Radio-Frequency (RF) data, this is straightforward as we can just index the signal at x(t−τ)x(t-\tau)x(t−τ). If we were to just index (2)(2)(2) like this, we would find a signal that shifts the III-, and QQQ-amplitudes, without shifting the phase of the carrier signal:

I(t−τ)⋅cos⁡(ωt)−Q(t−τ)⋅sin⁡(ωt)≠x(t−τ)I(t-\tau)\cdot \cos(\omega t) - Q(t-\tau)\cdot\sin(\omega t) \neq x(t-\tau)I(t−τ)⋅cos(ωt)−Q(t−τ)⋅sin(ωt)=x(t−τ)

This is why we need phase rotation to correct for this difference.
